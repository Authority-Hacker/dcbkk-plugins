# Source-faithful examples

Read only when a protected passage or no-change choice needs calibration. These examples are edits, not invitations to add background facts.

## Protected quotation and editable dashes

**Input**

> The customer said, “Ship it—after review.” The plan—built for speed—would help the team. The next phase—if approved—starts Monday.

**Possible edit**

> The customer said, “Ship it—after review.” The plan would help the team work faster. If approved, the next phase starts Monday.

The direct quote stays byte-for-byte. The writer's two dash interruptions become ordinary prose. Do not turn “starts Monday” into a dated promise or add a claim about the customer's approval.

## Vague source

**Input**

> AI-assisted coding serves as an enduring testament to the transformative potential of large language models. These tools unlock creativity at scale. Exciting times lie ahead!

**Possible edit**

> AI-assisted coding can give developers more room for creative work.

The edit cuts framing and generic closure. It makes no claim about speed, test quality, architecture, or measured productivity because the input supplied none.

## Already human

If a short draft is clear and has a distinctive voice, return it exactly, including paragraph breaks. Say briefly that no edit was needed. A scanner's isolated punctuation flag does not justify flattening the voice.
