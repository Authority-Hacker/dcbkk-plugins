# Edit comparison

Use when an edit raises a source-fidelity or voice question. Before delivery, compare the actual final text with the input:

- The point, supported details, claims, names, numbers, and uncertainty still mean the same thing; no new facts, examples, sources, opinions, or angles appear.
- Protected links, citations, direct quotations, code, placeholders, headings, tables, and frontmatter remain intact unless the user specifically requested a change.
- Strong human sentences, characteristic rhythm, useful tension, humor, and asides survive unless a concrete problem justified an edit.
- Empty framing, template repetition, generic closure, and distracting punctuation targeted by the brief are resolved. An isolated earned choice can remain with a reason.
- A no-change answer reproduces the source exactly, including paragraph breaks and formatting.

For linked file jobs, compare URL and placeholder literals mechanically as [file jobs](file-jobs.md) directs. Fix a failed comparison and check the repaired passage. A scanner exit `1` only reports candidates; review them in context.
